Average acceleration

Find the signed average acceleration from initial velocity, final velocity, and elapsed time.

Published · R0

Method and scope

Average acceleration a = (final velocity − initial velocity) ÷ elapsed time.

Calculate one-dimensional average acceleration for learning and general analysis. Intended for Learners, General physics use.

Inputs
  • Initial velocity — m/s, km/h, mph
  • Final velocity — m/s, km/h, mph
  • Elapsed time — s, min, h
SOURCE AND LIMITS
  • OpenStax, College Physics 2e, §2.4 Average Acceleration, ā = (vf − v0) / Δt. ↗

Assumptions: Velocities refer to the same one-dimensional coordinate axis and sign convention. Elapsed time is positive.

Limitations: The result is an interval average; it does not describe changes within the interval.
