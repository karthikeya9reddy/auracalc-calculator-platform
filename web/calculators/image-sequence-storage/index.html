Uncompressed image sequence size

Estimate uncompressed image-sequence storage from image dimensions, channels, bit depth, and frame count.

Published · R0

Method and scope

Bytes = width × height × channels × bytes per channel × frames.

Use uncompressed image sequence size for educational calculation or a clearly scoped arithmetic estimate. Intended for Learners, General educational use.

Inputs
  • Image width — 1
  • Image height — 1
  • Channels per pixel — 1
  • Bytes per channel sample — 1
  • Frame count — 1
SOURCE AND LIMITS
  • OpenEXR Technical Introduction; image channels are stored as pixel values and uncompressed storage is derived from dimensions and channel sample sizes. ↗

Assumptions: Every pixel has the same number of channels and bytes per channel. No compression, metadata, headers, mipmaps, or proxy files are counted.

Limitations: Actual media files include metadata and often compression; compression ratio depends on content and settings.

Method version 1.0.0 · Unit registry and result provenance are shown after calculation. This tool is limited to the documented scope.
