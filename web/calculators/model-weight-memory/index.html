AI model weight storage estimate

Estimate the raw storage for model weights from parameter count and bits per parameter.

Published · R0

Method and scope

Raw weight bytes = parameter count × bits per parameter ÷ 8.

Estimate raw model weight bytes for an explicitly chosen fixed precision. Intended for Learners, AI practitioners.

Inputs
  • Parameter count — 1
  • Bits per parameter — 1
SOURCE AND LIMITS
  • IETF RFC 1392, Internet Users’ Glossary, “An octet is 8 bits.” ↗
  • NIST, Binary Prefixes, 1 GiB = 2³⁰ bytes; 1 GB = 10⁹ bytes. ↗

Assumptions: Every parameter uses the same stated bit width. GB is decimal (10⁹ bytes) and GiB is binary (2³⁰ bytes).

Limitations: Some quantization formats use additional per-block metadata and do not use a uniform bit width.

Method version 1.0.0 · Unit registry and result provenance are shown after calculation. This tool is limited to the documented scope.
