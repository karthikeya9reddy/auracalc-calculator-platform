Function reference & conventions

sqrt(x), abs(x), ln(x), log(x), exp(x)
sin(x), cos(x), tan(x) — angles in radians. Convert degrees with angle * pi() / 180.
min(a,b), max(a,b), floor(x), ceil(x), round(x)
Constants: pi() and e(). Exponents associate right-to-left: 2^3^2 = 512. Unary minus: -2^2 = -4. Round uses ties toward positive infinity.

Real-number arithmetic only. Square roots need nonnegative inputs; logarithms need positive inputs. Use consistent units; the studio does not perform dimensional validation.
